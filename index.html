02 / Manifesto

Não é o que o software faz — é como ele faz as pessoas se sentirem.

É por isso que meu trabalho não termina no deploy. Um painel de chão de fábrica só está pronto quando o operador prefere usá-lo a voltar para o papel. Um site só está pronto quando o cliente entende, em cinco segundos, por que deveria continuar lendo.
